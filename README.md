# Grida Blog

The official [Grida blog](https://grida.co/blog).

To add or edit an article, follow the [writer guide](CONTRIBUTING.md). You can work entirely in your browser on GitHub.

```sh
pnpm install
pnpm dev
```

Open [localhost:3002/blog](http://localhost:3002/blog). Application development notes are in [AGENTS.md](AGENTS.md).
